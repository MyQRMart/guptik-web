Install

One node per house. The desktop app is the node. The phone is the remote. Same email on both is the pair — no QR required.

1. Desktop (the node)

  1. Install GupTik Desktop on Linux (or Windows when that build is published).
  2. Sign in with your MyQRMart / GupTik account.
  3. If this PC already has a GupTik Docker stack, the app reuses it. It will not create a second one.
  4. First time only: pick a parent folder. GupTik creates a GupTik/ folder inside it.
  5. Leave the app running. Gateway is :55000, database :55432.

Linux install path used here: ~/.local/opt/guptik-desktop. Menu name: GupTik.

Code: github.com/MyQRMart/guptik_desktop

2. Phone (the remote)

  1. Install the GupTik Android app.
  2. Sign in with the same email.
  3. Home → Node card: Connect. Same Wi‑Fi uses LAN; away from home uses your tunnel if it is up.

Code: github.com/MyQRMart/guptik

3. Browser (optional)

With the desktop stack running, any device on the LAN can open:

http://<pc-lan-ip>:55000/web

Updates: desktop app and node version separately. Settings → Updates. A node update rebuilds the gateway only — your files stay.
